# Meal frontend

Самостоятельный репозиторий интерфейсов Meal Planner: `front` (Next.js), `frontend_admin` (Vite), `design-system` (общие примитивы). Backend и миграции находятся в отдельном `meal_backend`; прямые импорты его исходников запрещены.

Сохранять публичный API, server/client-границы, проверки ролей и consent и fail-closed поведение внешних провайдеров. Моки предназначены только для разработки и тестов; production использует реальный API.

Контракты хранятся в `front/contracts` и `frontend_admin/contracts`. Изменять их явно по артефакту backend, проверять генераторы и совместимость. Инструкции приложений и продуктовые документы продолжают действовать.

Не хранить секреты, дампы, реальные данные, сборки и результаты QA в Git. Временные артефакты размещать только в отдельной папке `D:\AITemp`, после проверки удалять только собственные файлы с проверкой точного пути.

После изменения поднимать patch-версию затронутого npm-пакета через npm version --no-git-tag-version и синхронизировать lock и version-list.md. Для общих изменений обновлять корень. Проверки: `npm run check`, `npm run build`; браузерные и интеграционные проверки отдельно документировать как mock или real.
